
# Netflix Data Analysis & Power BI Dashboard

## Project Overview
An end-to-end data analysis project focused on exploring Netflix's content catalog using Power BI.

The project aims to uncover insights into Netflix's movies and TV shows, content distribution, release trends, and genre popularity.

## Tools & Technologies
- Power BI
- Power Query
- DAX
- Data Cleaning & Transformation
- Data Visualization

## Key Analysis
- Movies vs. TV Shows distribution.
- Content growth over the years.
- Top genres and categories.
- Content distribution by country.
- Ratings and content classifications.

## Key Insights
- Identified the distribution of movies and TV shows.
- Analyzed content production trends over time.
- Highlighted the most common genres and content categories.
- Explored geographical patterns in Netflix's content library.

## Recommendations
- Use content distribution insights to identify opportunities for expanding underrepresented genres.
- Analyze regional content trends to support localization strategies.
- Monitor content growth and genre performance to guide future content acquisition.
