
# 🎬 Netflix Data Analysis | Power BI Dashboard

An end-to-end Data Analytics and Business Intelligence project focused on exploring Netflix Movies and TV Shows using Microsoft Power BI.

This project transforms raw Netflix data into meaningful insights through data cleaning, transformation, analysis, and interactive visualization. It aims to uncover content trends, distribution patterns, and business opportunities within Netflix's content library.

---

## 📌 Project Overview

The objective of this project is to analyze Netflix's content catalog and understand its composition, distribution, and evolution over time.

The project uses Power BI to explore different business dimensions, identify patterns, and present findings through an interactive dashboard that supports data-driven decision-making.

## 🎯 Business Objectives

- Analyze the distribution of Movies and TV Shows.
- Identify content trends across different release years.
- Discover the most represented genres and categories.
- Explore the geographical distribution of Netflix content.
- Analyze content ratings and audience classifications.
- Identify meaningful patterns and opportunities to support content strategy.

## ❓ Business Questions

This analysis aims to answer the following questions:

1. What is the distribution of Movies compared to TV Shows?
2. How has Netflix's content library evolved over time?
3. Which genres are most represented in the catalog?
4. Which countries contribute the largest number of titles?
5. What are the most common content ratings?
6. What patterns can be identified in Netflix's content distribution?

Data preparation is an essential part of this project to ensure data quality and analytical consistency.

The preparation process focuses on:

- Exploring the dataset structure and data fields.
- Identifying missing values and data quality issues.
- Cleaning and transforming data using Power Query.
- Preparing fields for content, genre, country, and rating analysis.
